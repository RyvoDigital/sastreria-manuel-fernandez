3D SUIT CONFIGURATOR - REQUIREMENTS SUMMARY
============================================
Sastreria Manuel Fernandez - Atelier Website


WHAT WE WANT TO BUILD
---------------------
A web-based 3D configurator where clients can:
- View suits in 360-degree interactive 3D
- Change fabric colors in real-time
- Select different sizes/fits
- Customize design (buttons, lapels, pockets)
- Get price quotes based on their configuration


WHAT WE NEED FROM THE 3D DESIGNER
----------------------------------

1. MODEL STRUCTURE (Separated Parts)
-------------------------------------
The suit must be split into INDIVIDUAL mesh components:

Character Base:
- Body (skin only)

Suit Jacket Parts:
- Jacket fabric (main body)
- Lapel (notch/peak/shawl variants)
- Buttons (1-btn, 2-btn, 3-btn, double-breasted variants)
- Lining (interior)
- Pockets (left, right, breast)
- Ticket pocket (optional)

Pants Parts:
- Pants fabric
- Waistband
- Cuffs (with/without variants)
- Pockets

Shirt Parts:
- Shirt fabric
- Collar
- Cuffs

Why: Each part needs independent material assignment for color changes


2. MATERIALS & TEXTURES
-----------------------
Each fabric part needs PBR texture maps:
- Albedo/Diffuse (base color)
- Normal map (fabric weave texture)
- Roughness (shiny vs matte)
- Metallic (for buttons only)
- Ambient Occlusion (shadow details)

Fabric Library Needed:
- Wools: Prince of Wales, Houndstooth, Birdseye, Plain, Flannel
- Specialty: Seersucker, Mohair blend, Cashmere blend
- Colors: Navy (3 shades), Charcoal (2), Black, Grey (3), Brown (2)


3. SIZE VARIATIONS
------------------
Option A - Morph Targets (RECOMMENDED):
Single model with shape keys:
- Slim fit (chest -5%, waist -8%)
- Regular fit (base)
- Relaxed fit (chest +5%, waist +5%)

Option B - Separate Files:
- suit_slim_fit.glb
- suit_regular_fit.glb
- suit_relaxed_fit.glb


4. DESIGN CUSTOMIZATION OPTIONS
--------------------------------
Each option needs to be a separate mesh that can show/hide:

Jacket Styles:
- Button count: 1-btn, 2-btn, 3-btn, Double-breasted (6x2)
- Lapel type: Notch, Peak, Shawl
- Lapel width: Slim (2.5"), Standard (3"), Wide (3.5")
- Vents: None, Single center, Double side
- Pockets: Flap, Patch, Jetted

Pants Styles:
- Rise: Low, Mid, High
- Pleats: Flat front, Single, Double
- Cuffs: No cuff, 1.5 inch cuff


5. FILE FORMAT SPECIFICATIONS
------------------------------
Format: GLB (Binary GLTF)
- Self-contained single file
- Coordinate system: Y-up
- Units: Meters (character ~1.75m)
- Origin: Character feet at (0,0,0)

Performance Targets:
- File size: Under 5MB per model
- Triangle count: Under 50,000
- Texture resolution: 1K (1024x1024)
- Load time: Under 3 seconds

Optimization Required:
- Draco compression enabled
- Remove unused vertices
- Merge duplicate materials
- Texture atlasing


6. ANIMATIONS
-------------
Idle Animation:
- Subtle breathing loop (4-6 seconds)
- Chest expansion 2-3mm
- Shoulder rise/fall
- Weight shift between feet

Transitions:
- Smooth crossfade when changing options (300-500ms)
- No popping or sudden changes


7. WEB INTEGRATION
------------------
Tech Stack:
- Next.js 16+ (React framework)

- React Three Drei (3D helpers)

UI Components Needed:
- Color picker (fabric swatches)
- Style selector dropdowns/cards

SUMMARY FOR 3D DESIGNER
-----------------------
To make this work, we need:

1. ONE model file with parts SEPARATED (not merged)
2. Materials that can change color at runtime
3. Design variations as separate meshes (hide/show)
4. File size under 5MB (compressed)
5. Smooth idle animation

The key is: everything must be INDEPENDENT so code can control it.
Merged meshes = can't change colors separately.
No morph targets = can't change sizes smoothly.
Too heavy = slow website = clients leave.
